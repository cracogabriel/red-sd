# mflix Java Client

A Java Swing GUI client for the mflix movie management service.  
Communicates with a Python TCP server using Protocol Buffers.

> **The server must be running before you start the client.**

---

## Project Structure

```
client/
├── compile-and-run.sh
├── movie.proto
├── MovieClient.java
├── connection/
│   └── ServerConnection.java
├── gui/
│   ├── MainWindow.java
│   └── dialogs/
│       ├── AddMovieDialog.java
│       ├── GetMovieDialog.java
│       ├── UpdateMovieDialog.java
│       ├── DeleteMovieDialog.java
│       ├── SearchGenreDialog.java
│       └── SearchActorDialog.java
└── movies/  -- files generated by protoc (do not edit)
```

---

## Requirements

- Java 17 or higher
- `wget` and `unzip` (used by the build script to download dependencies)

Check your Java version:

```bash
java -version
```

---

## How to Run

**1. Start the server first** (in a separate terminal):

```bash
cd server/
python server.py
```

**2. Give execute permission to the build script** (first time only):

```bash
chmod +x compile-and-run.sh
```

**3. Run the client:**

```bash
./compile-and-run.sh
```

The script will automatically:

- Download the Protobuf Java library (`protobuf-java-3.21.12.jar`)
- Download and extract the `protoc` compiler
- Generate Java classes from `movie.proto`
- Compile all `.java` files
- Launch the GUI

---

## Features

| Button          | Operation                   |
| --------------- | --------------------------- |
| add movie       | Create a new movie          |
| get movie       | Fetch a movie by ID         |
| update movie    | Load and edit a movie by ID |
| delete movie    | Delete a movie by ID        |
| search by genre | List movies by genre        |
| search by actor | List movies by actor name   |

---

## Notes

- The client connects to `127.0.0.1:5000` by default. To change this, edit the `host` and `port` variables in `MovieClient.java`.
- The `movies/` folder is generated automatically — do not edit those files manually.
- The `bin/` folder is recreated on every run.

# mflix Python Server

A TCP server that handles movie management operations on a MongoDB Atlas database.  
Receives requests from the Java client using Protocol Buffers.

---

## Requirements

- Python 3.10 or higher (required for `match` statement)
- pip packages (see [Installation](#installation))
- A MongoDB Atlas account with the **sample_mflix** dataset loaded

Check your Python version:

```bash
python3 --version
```

---

## Installation

**1. Install dependencies:**

```bash
pip install pymongo python-dotenv protobuf dnspython
```

**2. Generate the protobuf Python file:**

```bash
protoc --python_out=. movie.proto
```

This will generate `movie_pb2.py` in the same directory.

---

## Environment Variables

The server reads the database password from a `.env` file.  
You must create this file before running the server.

**Create a `.env` file in the same folder as `server.py`:**

```
DB_PASSWORD=your_mongodb_password_here
```

> **Never share or commit your `.env` file.** Add it to `.gitignore`:
>
> ```
> echo ".env" >> .gitignore
> ```

The connection string uses the password to connect to MongoDB Atlas:

```
mongodb+srv://sd-red-mongodb:<password>@cluster0.nyepcaz.mongodb.net/
```

The password is URL-encoded automatically to handle special characters.

---

## How to Run

```bash
python3 server.py
```

Expected output:

```
starting server...
connecting to MongoDB...
connected with MongoDB! total moovies: 21349

listening on 0.0.0.0:5000
```

The server listens on **port 5000** and accepts connections from any interface (`0.0.0.0`).  
Each client connection runs in its own thread.

## Supported Operations

| Operation       | Description                                                         |
| --------------- | ------------------------------------------------------------------- |
| `CREATE`        | Inserts a new movie. Requires `title` and `year`.                   |
| `GET`           | Fetches a single movie by MongoDB ID.                               |
| `UPDATE`        | Updates a movie by ID. Requires `title` and `year`.                 |
| `DELETE`        | Deletes a movie by ID.                                              |
| `LIST_BY_ACTOR` | Returns up to 20 movies matching the actor name (case-insensitive). |
| `LIST_BY_GENRE` | Returns up to 20 movies matching the genre (case-insensitive).      |

Errors are returned to the client as a `Response` with `success = false` and a descriptive `error` message.
